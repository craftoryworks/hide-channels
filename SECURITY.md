# Security policy

## Supported versions

Only the latest version published in the browser stores receives fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems. Email **contact@craftory.works** with:

- what the problem is and where (file, page or feature),
- steps to reproduce,
- the extension version and browser.

You will get a reply within a few days. Once the issue is confirmed, a fix is released through the stores and the report is credited in the release notes, unless you prefer to stay anonymous.

## Scope

The extension runs only on twitch.tv and kick.com, stores its data in the browser's extension storage and sends no data anywhere. Reports about Twitch or Kick themselves belong to those services.
